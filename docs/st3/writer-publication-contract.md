# Private native publication source checkpoint

This U0 source unit is bound by Root message/6eec962119335ca5 in the existing writer-admission claim. Speed owns integration. It is private, unqualified source: no runtime producer is activated or certified, and all authored controls are **UNRUN, including compilation**. The independent admission change in PR2644 is merged; this unit is not its follow-up performance fix.

`sqlite::publication_contract` owns a pure payload separately from positive/negative keyed read evidence. Its comparer refuses missing predicates/mutation tokens, changed source identity and stale facts. Producer-defined tokens are not installed by the helper. Calling `certification` always refuses because transactional all-mutator coverage has not been supplied. No Store index/rowid/timestamp token, generic callback, existing IVM prepared bridge or copied boolean becomes a native certificate. The root-generation, evidence storage/size/trim/per-write overhead and command/outbox format decisions remain unapproved.

The declared read set must cover exact keys, ranges, negative membership, ordering/limits and aggregates, rules, repairs, membership/key revocation, local lease/cancel/incarnation and same-index derived changes. Storage must maintain every relied-on mutation identity transactionally for every legacy/raw/autocommit caller, or fail closed across unsupported intervals/schema/hooks/other writers. Lifetime/reopen/ABA semantics are prerequisites. Complete query-to-mutator mapping and liveness under unrelated ingest remain producer work. Extra input rows must not imply whole-history recomputation or global-MAX invalidation.

`WriterTransaction::commit_validated` is the one native seam added: the existing managed prepare/body/maintenance/finalizer order remains, then a private check sees that same transaction immediately before COMMIT. Existing `commit_checked` delegates without changing its check or budget. Failure drops the uncommitted transaction; a landed COMMIT cannot be undone by later observer failure. The callback is not certified short, cannot supply source coverage by convention, and no arbitrary SQL callback is offered as a prepared execution API. Prepared publishers would need validation at acquisition AND after finalizers, compatible group-commit semantics, and bounded total SQL/trigger/index/finalizer/observer work. No producer uses this new seam outside controls.

A managed error is preserved as `Unknown`, rather than interpreted as a safe retry or proof of rollback; only an explicit successful native rollback can supply that knowledge. No operation result journal exists here. F6 requires existing proven durable identity/outcome linkage or separately approved persistence before recovery certification. Native committed-authority callbacks still run **after transaction resolution**, on the same connection, before ACK/physical return. This unit moves none of them into an uncommitted transaction, after ACK, or after physical return. F5 requires transactional evidence rollback followed by observers reading resolved unchanged authority, and committed-unacknowledged treatment if an observer fails after COMMIT.

`UncertifiedCompletion` keeps synchronous authority, actual queue return and real child/backing completion unresolved. Its managed-success conversion does not mint an ACK. Current guard drop sends a connection; actual queue receive, or an actual subsequent loan, establishes reacquisition. A batch result precedes completion of the batch function's tail. No model state or flag proves either event. Executor-owned receipts and cost/lifetime review are still missing. Any future ACK-after-availability guarantee needs explicit implementation; current native minimum remains durable COMMIT plus synchronous authority first.

No post-return effect/reclamation is implemented. F4 requires each effect to have same-transaction durable intent or a proven deterministic reopen recomputation, with order/idempotency/references and actual child closure. F8 forbids reclaiming backing used by an active reader even if a cursor expires; current cursor contracts/timeout/caps are unchanged. This source invents no wire state, new outbox, generation/root or independently writing live connection. No in-writer replay fallback, retry-until-lucky, changed FULL mode, queue cap/timeout/group limit, schema or wire API.

## Authored controls — all UNRUN

The fixture uses real SQLite and the real native writer. Fixture-only epochs/triggers demonstrate a closed toy mutation domain, not proposed production schema/coverage. Controls cover matching publication without manufactured native completion; same-index authority revocation; negative insertion and delete/reinsert ABA; finalizer invalidation rolling back prepared output and finalizer writes; finalizer failure; deferred-FK COMMIT failure retaining unknown outcome; batched and lent native callbacks blocking ACK/next acquisition until released; observer panic after COMMIT retaining durable output; missing negative token/predicate refusal; and raw capture bypass where equal facts explicitly do not yield certification.

Future qualification still needs complete producer mapping, ordinary-write overhead, real source/consumer lifetime/reopen/ambiguous-commit controls and all current review gates. Neither controls nor this document close Intake F1-F6/F8. Source-authoring permission is not native execution or public Ready approval.
