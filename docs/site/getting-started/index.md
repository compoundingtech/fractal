# Getting started

Start on one machine under your own user account. Each person currently runs their own fleet.

## Three ways in

1. **With your coding agent:** hand it [the unattended setup guide](with-your-agent.md). It installs Fractal and declares a small first mission, with success checks at each stage.
2. **Hands-on:** [install Fractal](install.md), declare your [first agent](first-agent.md), and start your [first mission](first-mission.md).
3. **Understand, then adopt:** read [Understand Fractal](../concepts/index.md), pick a workflow with a measurable goal, and introduce only the pieces it needs.

You need a supported machine and an authenticated coding harness. Fractal uses your harness account and quota. Finish native sign-in and workspace trust before expecting unattended work; Fractal cannot create an account or answer authentication on your behalf.

For an existing installation, start with [upgrading](../guides/upgrading.md), not a fresh setup. Keep working state and keys intact.
